Multimodal User Interfaces

What are Multimodal User Interfaces?

Multimodal User Interface is an approach to user interface design that allows for multiple input modes instead of a single channel, the goal is to improve usability and user satisfaction.

Effect on Majority of Canadian Society

Multimodal User Interface allows for reduced cognitive load on users, when there are multiple input modes, users can choose the input mode they are most comfortable with, allowing for them to have a better experience navigating, and decreasing stress on users.
